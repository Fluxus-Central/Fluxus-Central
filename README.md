# Fluxus Central

Fluxus Central is an independent, community-driven project built around the Fluxer ecosystem.

It brings public ecosystem signals into one clear place: service health observations, development activity, releases, public news, and source-backed findings. The goal is to make Fluxer-related activity easier to follow without replacing the original sources or claiming affiliation where none exists.

## What Fluxus Central does

- Monitors publicly available Fluxer service status information.
- Organizes public development activity and release signals.
- Connects observations to their original public sources.
- Presents information through a read-only, privacy-conscious public interface.
- Keeps repository-derived data limited to explicitly approved public repositories.

Fluxus Central does not collect private data, expose database credentials, or act as an official Fluxer service. It is an independent community project that evolves alongside the ecosystem.

## Project status

Fluxus Central is an evolving project. Public data is shown with source metadata and honest availability states so that missing information is not presented as a fabricated result.
